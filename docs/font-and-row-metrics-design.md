# 多字体与按行尺寸：设计规格

面向**实现者**。用户向说明写在 [README.md](../README.md)，不变量写进
[AGENTS.md](../AGENTS.md)；本文只回答"怎么做、为什么这么做、怎么验证"。

两个需求、两批实现（分开提交，各自带断言）：

* **A 批：字体**——全局回退链 + 按段覆盖，**未配置时零成本**。
* **B 批：按行字号与高度**——设置项 + 行首标签两套，标签覆盖设置项。

---

## 1. 为什么不能"总是走多字体通路"

多字体意味着对每段文字做**字形覆盖查询**（`GetGlyphIndicesW`，缺字形返回 `0xFFFF`），再按
(族, 字号) 取字体对象。一条纯 ASCII 行根本不需要这些：任何常见拉丁字体都能画，查一遍纯属浪费，
而面板是**每帧重绘**的（`PaintPanel` 每次重建字体，见 AGENTS §5.1 关于"字体每帧重建"的教训）。

所以本设计的第一条规则是**成本闸门**：

> **只要这行原文没有任何字体配置、且全局回退链为空，就走今天那条路**：一行只按字号建一个字体、
> 所有段共用、**零覆盖查询、零额外分段、零第二字体对象**。

闸门在**配置期**判定一次（`ReadSettings` 扫描原文），不在每帧判定。

## 2. 设置项（A 批）

| 键 | 类型 | 默认 | 说明 |
| :-- | :-- | :-- | :-- |
| `FontFamily` | 字符串 | `Segoe UI` | **已有**。主字体族 |
| `Fallback fonts` | 字符串 | 空 | **新增**。分号分隔的候选链，如 `Microsoft YaHei UI;Segoe UI Emoji`。空 = 不回退（等于今天的行为） |

`ModSettings` 增加：`WCHAR fallbackFonts[kMaxFontFamilies][...]` + `int fallbackFontCount`，
以及**每行一个布尔** `bool rowFontMarkup[kMaxRows]`（配置期扫描结果）。

解析规则：去掉首尾空白、跳过空项、上限 `kMaxFontFamilies`（建议 4）；超出的项丢弃并在
`ReadSettings` 里记一次**有界日志**（不要每帧打）。

---

## 3. 行内标签（A 批）

```
[[font:族名]]     开始一段（族名可含分号，表示这一段自己的候选链）
[[/font]]         结束这一段（缺省则到行尾结束）
```

语义：段内文字先在**标签给的候选链**里选，再退到**全局回退链**；都不覆盖时退到主字体。

容错（**硬要求**）：拼错、未闭合、族名超过 `kMaxFontFamilyChars` 的标签**当作普通文本绘制**，
并记一次有界日志。**绝不允许因为标签问题让整行消失**——AGENTS §5.1 的第一条教训就是"一行算成 0 宽
会让 GDI+ 把整行裁掉"。

标记机制与现有的 `[[ring:…]]` 完全一致：展开期把标签换成**私用区标记**
（`kFontMarkStart` + 候选链索引 + `kFontMarkEnd`），`BuildRowLayout` 剥掉标记并给每个 `TextSeg`
带上候选链索引。这样"剥标记"只有一处实现，测试与绘制共用。

## 4. 绘制侧（A 批）

* **候选选择**是纯函数，覆盖判定**以函数指针注入**：

  ```cpp
  // 返回候选链里第一个覆盖 run 全部字符的族索引；都不覆盖则返回 0（主字体）。
  static int PickFontFamily(const WCHAR *run, int len, const FontFamilyList &list,
                            bool (*covers)(int familyIndex, WCHAR ch));
  ```

  断言注入一张假覆盖表即可覆盖全部分支（含"都不覆盖"与"空段"）。

* **纯 ASCII 段跳过查询**：段内没有 `> 0x7F` 的字符就直接用主字体。这条写进代码注释与 README，
  因为它是性能承诺的一部分（一个全英文面板可以完全不付多字体的代价）。

* **覆盖查询缓存**：定长静态表 `{familyHash, ch, covered}`，线性探测，容量建议 256，**无堆分配**
  （与 mod 一贯的零分配纪律一致）。未命中才调 `GetGlyphIndicesW`（用一个内存 DC + 按需建的 HFONT，
  同样缓存）。

* **字体对象缓存**：`GpFont*` 按 (族, 字号) 缓存，上限建议 8；设置变更时整体释放——与图标缓存
  （`ReleaseSlotImage`/`DisposeIconImage`）同一套路，别各写一套生命周期。

## 5. 按行字号与高度（B 批）

### 5.1 两套载体

| 载体 | 例子 | 优先级 |
| :-- | :-- | :-- |
| 设置项 | `Row 2 font size` / `Row 2 height`（`0` = 继承全局） | 低 |
| 行首标签 | `[[size:18]]` / `[[h:44]]`（**只认行首**，可在文本前连续出现） | 高（覆盖设置项） |

标签放在行首而不是任意位置，是为了不引入"局部行高"这种无法定义的东西：**行高是行的属性**。
`[[size:…]]` 放在行首同时也成为该行**默认字号**，段级字号不在本批范围内。

### 5.2 影响面（这就是它必须单独一批的原因）

行高可变会牵动：

1. **面板高度**：`ComputeGeometry` 不能再用 `rowHeight * rowCount`，要累加每行高度 + 行间距；
2. **命中测试**：`WM_NCHITTEST` 要对每行算上下边界（按累加高度查表，别每次循环算）；
3. **图标盘与环**：`IconPlateCenterForRow` 已经接收 `rowTop`，把"行高"也传进去（盘的直径跟随
   **该行**字号），环几何同源改；
4. **入场动画**：`g_displayHeight` 的目标高度来自累加结果，收回/展开的关键帧不改（它们只关心
   起止高度），但**测试里那些假设 `rowHeight * n` 的断言要跟着改**；
5. **岛上卡片**：与行无关（卡片自己的几何），不动 —— 但要在文档里写明"卡片不受行高影响"，免得
   下一个人以为漏了。

### 5.3 不变量

* 每行高度 = 该行字号推导出的**最小**高度与配置高度的较大者（字号涨了行不能反而放不下）；
* 面板总高 = Σ 行高（+ 内边距），且**下限**仍是标签高度（收起时不消失）；
* `[[h:…]]` 比 `[[size:…]]` 先解析（行高是行属性，字号只影响内容），两者互不影响；
* 标签只认行首：出现在文本中间的 `[[size:20]]` 当普通文本（**不要**半路改行高）。

## 6. 断言清单（写进 `test-layout.cpp`）

**A 批**

1. `PickFontFamily`：候选链命中第一个覆盖的族；都不覆盖 → 主字体；空段 → 主字体；
   链长上限被遵守；
2. 覆盖查询**次数**：纯 ASCII 段查询次数为 0（用计数器注入），含 CJK 的段只查一次/字符且在
   缓存命中后为 0；
3. **成本闸门**（本设计的核心断言）：`rowFontMarkup[r] == false` 且回退链为空时，
   "本行是否需要多字体通路"为 false——把它做成纯函数 `RowNeedsFontPath(markup, hasList)`，
   两条断言（真/假）钉住；
4. 标签容错：未闭合 `[[font:X]]` → 当普通文本，**行宽与不含标签时一致**（防止"标签吃掉整行"）；
5. 设置解析：`Fallback fonts` 分号列表 → 项数与内容；全空 → 计数 0（闸门因此关闭）。

**B 批**

6. 行高解析：设置项 → 行高；行首标签覆盖设置项；非行首标签被忽略；
7. 面板总高 = Σ 行高（含"字号涨了行不会放不下"的下限情形）；
8. 命中测试：每行的上下边界与累加结果一致，且相邻行边界**不重叠**；
9. 回归：默认配置（所有 `0`、无标签）下，总高与命中结果与今天**逐值相同**——这条是防止
   重构悄悄改变外观的护栏，必须最先跑。
